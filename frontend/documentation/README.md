# Documentación del Frontend — Sistema de Triage Académico

Bienvenido a la documentación del frontend. Este proyecto es una aplicación web construida con **Angular 21** que permite gestionar solicitudes académicas con ayuda de inteligencia artificial.

## Resumen rápido del proyecto

- **Nombre:** Sistema de Triage Académico
- **Framework:** Angular 21 (TypeScript)
- **UI:** Angular Material Design
- **Backend esperado:** API REST en `http://localhost:8080`
- **Puerto del frontend:** `http://localhost:4200`
- **Idioma de la interfaz:** Español
